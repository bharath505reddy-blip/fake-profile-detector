Obtaining API Keys

  • GitHub — github.com/settings/tokens (no auth needed for public data, token increases rate limit)
  • Twitter/X — developer.twitter.com → Bearer Token
  • YouTube — Google Cloud Console → YouTube Data API v3
  • Instagram — Facebook Developers → Basic Display API
  • LinkedIn — linkedin.com/developers → OAuth 2.0 access token
  • Discord — discord.com/developers → Bot token
  • TikTok — developers.tiktok.com → Research API key
  • Reddit — No key required (public JSON API)
